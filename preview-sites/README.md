# ULTIMA · Gemeinsames Vorschau- und Portal-Repository

Dieses Repository bündelt die zentral verwalteten Website-Vorschauen und Portal-Module. Eigenständige KI-Produkte behalten ihre eigenen Repositories, Persönlichkeiten, Systemprompts und Deployments; sie werden nicht in eine generische Einheits-KI umgebaut.

## Enthaltene statische Vorschauen / Module

| Modul | Repository-Pfad | Render-Adresse |
|---|---|---|
| Cosmican Lux Syndicate | `cosmican/` | https://ultima-central-45ne.onrender.com/cosmican/ |
| Aurelis Investment – Konzeptvorschau | `aurelis-investment/` | https://aurelis-investment.onrender.com/ |
| ULTIMA App Center | `app-center/` | https://ultima-central-45ne.onrender.com/app-center/ |
| ULTIMA Central | Repository-Wurzel | https://ultima-central-45ne.onrender.com/ |

## Deployments

- **ULTIMA Central** veröffentlicht die Repository-Wurzel als statische Website.
- **Aurelis Investment** veröffentlicht ausschließlich `aurelis-investment/` als separaten Render Static Site Service.
- Änderungen an Dateien im gemeinsamen Repository können automatische Deployments für mehrere verbundene Render-Dienste auslösen.

## Grenzen und Statushinweise

- Die Aurelis-Investment-Seite ist eine neu aufgebaute Konzeptvorschau. Sie ist keine Wiederherstellung des nicht erreichbaren ursprünglichen GitHub-Repositories `ariandomimate-blip/Aurelis-Investment`.
- Die Vorschauseite enthält keine Einzahlung, Verwahrung, Finanzberatung oder Renditezusage.
- Cosmican enthält das importierte Facebook-Archiv. Anhänge werden nur eingebettet, wenn die tatsächlichen Mediendateien im Repository vorliegen.
- Dieses Repository ist ein zentraler Sammelpunkt für Vorschauseiten und Portale, nicht die Zusammenlegung aller unabhängigen Backend- und KI-Repositories.
