## Environment-variable configuration policy

- Existing Render variables must be preserved; only merge additional values after checking the exact app code and its `.env.example` / `render.yaml`.
- Do not overwrite all variables (`replace=true`) during maintenance.
- Never put real API keys, bot tokens, database credentials, signing keys, OAuth secrets, or payment secrets into Git or this report.
- Render's current variable values are not exposed by the connected service metadata. This report therefore records required names, not values.
- Empty values in `.env.example` are missing credentials, not safe production defaults. Do not write empty placeholders into Render.
- Use Render `generateValue` for application secrets when supported by the Blueprint; generate secrets in the Render dashboard for manually managed services.
